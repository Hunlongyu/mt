原型说明

启动面板按原版 HLaunch 的紧凑网格与底部分类还原；手势和黑屏仅在统一设置中配置。

  • 点击图标演示启动；右键条目可编辑，右键空槽或 Insert 可在原位置注册项目。
  • 启动面板内直接输入，或 Ctrl+F 搜索全部分类；Esc 先清空搜索，再收起面板。
  • 滚轮或 Tab / Shift+Tab 切换分类，PageUp / PageDown 翻页；菜单中也有对应入口。
  • 可拖动条目到精确槽位或其他分类；空槽会保留。
  • 剪贴板通过图标过滤文本、图片、文件或收藏；默认不选中任何图标，显示全部。再次点击选中图标可取消过滤。
  • 点击放大镜或 Ctrl+F / / 打开搜索时隐藏分类图标；Esc 清除并收起搜索，恢复原过滤选择。选中记录后 Enter 回贴、Space 预览；低频操作位于更多菜单。
  • 切换浅色 / 深色查看两套主题，示例变更保存在当前浏览器。

原型不会启动真实程序、监听系统剪贴板、修改开机启动或锁住屏幕。密码不会保存。只有明确点击“复制”时，才尝试写入浏览器剪贴板。
