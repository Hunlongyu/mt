MT 的首个公开版本，将启动面板、剪贴板历史、鼠标手势和黑屏遮挡整合到一个 Windows 托盘入口。

## 功能

- 启动面板：默认 4 列 × 7 行，支持分类、固定槽位、搜索、拖放、快捷键与屏幕边缘唤起。
- 剪贴板：历史搜索、收藏、置顶、预览和回贴；保存文本、HTML、RTF、图片、文件列表及可序列化的应用格式，支持纯文本粘贴。
- 鼠标手势与黑屏遮挡：统一设置、独立开关；黑屏遮挡不代替 Windows 账户锁定。
- 开机启动：登录 Windows 后启动 MT，沿用当前数据目录，不接管旧工具启动项。
- 管理员支持：通过同一个 EXE 的受限辅助模式处理回贴和手势，开启时及之后每次启动均由 Windows UAC 确认。
- 只读导入 Hopy 历史、HLaunch 分类和启动项；不迁移 hua、BlackLock 配置、旧偏好或旧自启。
- 纯中文、浅色/深色/跟随系统主题；统一 GitHub Releases 更新入口。

## 下载

- `mt-0.1.0-windows-x64.zip`：推荐下载，解压后运行 `mt.exe`，附带许可证。
- `mt-windows-x64.exe`：单个 Windows x64 程序，也用于后续自动更新。
- `SHA256SUMS.txt`：下载文件的 SHA-256 校验清单。
- `mt-0.1.0-source-with-dependencies.zip`：完整应用源码、固定 Qt/WIL 源码与重新构建说明。

采用 Qt 6.11.2 和静态 CRT，无需另装 Qt；仍依赖 Windows 系统组件。主要开发验证环境为 Windows 11 x64。

## 数据与验证范围

开机启动、管理员支持、鼠标手势和黑屏遮挡默认关闭。数据与 EXE 分开存放，常规设置中可查看目录；也可通过 `--data-dir` 指定。

旧 MT 开发版剪贴板库升级至 schema 2 前会生成一致性备份，再以事务升级。只有 RTF/应用格式而没有文字表示的条目不支持纯文本回贴。依赖原进程的 OLE 对象和特殊句柄不能保证跨重启恢复。具体范围和恢复步骤见仓库的 `docs/system-integration.md`。

本机静态构建、9 组 CTest、独立目录启动与更新替换/失败保护已通过；标签发布工作流会重新验证。真实登录自启、UAC 同意/取消、管理员窗口回贴/手势、多显示器与混合 DPI、真实旧数据导入和干净机器部署仍待验证。尚未完成两个正式版本之间的在线升级实测，当前 EXE 无 Authenticode 签名。
