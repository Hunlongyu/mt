本次更新集中修复设置界面、启动面板交互与图标加载，并完善单文件自更新。

## 升级说明

**程序文件名统一为 `mt.exe`。v0.1.0 只识别旧更新资产名，升级到本版需手动下载一次；之后可继续使用应用内更新。**

退出旧版后替换程序即可，保留原数据目录；使用自定义数据目录的用户继续传入原 `--data-dir`。新安装默认使用 `%LOCALAPPDATA%\dev.hly.com\mt`，已有旧数据且新目录不存在时继续使用旧目录，不自动迁移或清空历史。

## 改进与修复

- 常规与外观设置合并，精简冗余说明和不可调整的固定行为卡片，不再展示数据位置；“黑屏遮挡”统一显示为“锁屏”。
- 修复设置下拉菜单裁切、更新按钮拥挤和不透明度设置行高不一致；提示气泡恢复 Qt 默认外观并跟随系统主题。
- 托盘“关于”直接进入设置的“关于 MT”，保留未保存内容；设置标题不再重复显示 MT。
- 优化启动面板标题、悬浮反馈、空槽和搜索；按住空白处可拖动整个面板，保留启动项拖放与分类重排。
- 图标加载复用有界后台辅助进程，优先处理可见项目并使用缓存，减少重复启动进程的开销。
- 启动面板主窗口支持右键手势，普通右键点击仍打开菜单；修复隐藏重开后的接纳状态，管理员支持开启时也能执行面板内动作。
- 单文件更新及回退以正常窗口方式重启，避免更新后窗口无法唤起；成功启动后清理临时助手，保留恢复备份，并保留用户原有程序路径和文件名。
- 应用 Logo 移除外围白底，EXE、窗口与托盘保持一致。

管理员窗口（例如以管理员权限运行的任务管理器）需要在常规设置中开启“管理员窗口支持”，并确认 Windows UAC 提示；主界面仍以普通权限运行。“锁屏”仍为屏幕遮挡，不代替 Windows 账户锁定。
