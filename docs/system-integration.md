# 系统集成与数据

## 开机启动

设置 → 常规 → 开机启动。开启后在当前用户登录 Windows 时运行当前 `mt.exe`，并继续使用当前数据目录；启动后是否显示面板由“启动时隐藏主面板”控制。

仅管理 `HKCU\Software\Microsoft\Windows\CurrentVersion\Run` 下的 `MT` 值。保存失败时回滚本次修改，不覆盖属于另一安装位置或数据目录的同名值。预览模式禁用此开关，测试使用独立注册表路径，不修改真实 Run 项。

建议先将 EXE 放到固定目录，再启用自启。需要移动 EXE 或更换数据目录时，先在原实例关闭自启，移动后重新开启。路径含空格、中文会正确引用；完整命令超过 260 字符时拒绝注册并提示缩短路径。它是登录启动项，不是开机服务，也不接管 Hopy、HLaunch、hua 或 BlackLock 的自启。

## 管理员窗口

设置 → 常规 → 管理员支持。普通权限主界面通过 Windows UAC 启动同一个 EXE 的受限辅助模式，处理回贴、Alt 热键菜单抑制、手势动作及必要的鼠标点击回放。打开程序、链接和目录仍由普通权限宿主处理。

开启时以及保存开启状态后的每次启动都会申请权限。取消或连接失败时继续保留普通窗口功能；可关闭该开关并保存，再重新开启。不会建立绕过 UAC 的计划任务。当前方案面向同一 Windows 用户的权限提升；不承诺跨用户凭据、系统/受保护进程或安全桌面的控制能力。

辅助模式没有托盘、数据存储或全局钩子。双方检查管道对端 PID、父进程创建时间、程序路径和会话；请求有大小、数量、有效期与目标窗口身份限制。断开、主进程退出或心跳过期后辅助进程退出；安装更新前确认它已释放 EXE。

目前已验证禁止执行输入的辅助进程握手、往返、生命周期和错误路径。真实 UAC、提权编辑器回贴、管理员窗口鼠标点击/手势仍待桌面实测；隔离测试不代表这些场景已验收。

## 剪贴板格式

同一条记录可保留文字、HTML、图片、文件列表和额外的可序列化 MIME 数据，包括 RTF、Windows `Rich Text Format` 及应用自定义字节格式。重启后普通回贴恢复这些格式，接收程序决定使用哪一种。额外格式参与内容去重，不把相同文字但格式不同的内容合并。

纯文本回贴去除 HTML、RTF 和应用附加格式；文件列表转为路径文本。图片沿用原行为，仍回贴图片。只有 RTF 或应用格式而没有文字表示时，普通回贴可用，纯文本回贴会明确说明不可用；不会把界面摘要写进剪贴板。RTF 当前保留原始数据，不提供 RTF 专用排版预览。

每次最多接受 64 种来源格式，附加字节总计不超过 16 MiB。已有文字、HTML、文件列表和图片大小限制继续生效。进程内 OLE 标识、对象链接、剪切移动副作用及监视标记不会重放；敏感标记沿用独立的敏感内容处理。依赖原进程的 OLE 对象、延迟渲染接口或特殊句柄不能保证跨进程/重启恢复，不等同于支持所有应用私有格式。

## 旧数据导入

| 入口 | 内容 |
| --- | --- |
| 设置 → 剪贴板 → 从 Hopy 导入 | 历史文本、HTML 附属内容、图片、文件列表及时间、收藏、置顶和敏感标记 |
| 设置 → 启动面板 → 从 HLaunch 导入 | 分类、启动项、参数、路径、槽位及必要快捷方式副本；读取旧列数用于位置映射 |

选择旧工具的数据目录并确认后，只读读取源文件，合并到 MT 当前数据目录。导入器已有合成数据测试，尚未对用户真实旧数据执行导入。Hopy 缺少图片的记录会跳过，HTML 附属文件缺失时保留可用文字；结束提示导入/跳过数量。源版本或结构错误会中止，原始文件保持不变。

范围仅限上述数据。**不迁移 hua、BlackLock 配置，也不导入旧工具偏好、密码或自启项。** 必要的 HLaunch 列数读取不代表接管旧界面设置。文件历史保存的是路径，不是所指文件的备份。

## 数据库升级与恢复

MT 剪贴板数据库升级至 schema 2，增加附加格式列。首次打开 schema 1 库时，SQLite 使用 `VACUUM INTO` 在同目录创建 `clipboard.sqlite.schema1-<UUID>.bak` 一致性备份，包含已提交 WAL 内容；备份成功后在事务中升级。不认识的更高版本、缺少版本标记的非空数据库、备份失败或升级失败会报错并保留数据，不删库重建。

需要退回旧程序时，退出全部 MT 实例并先完整复制当前数据目录作为保留副本。另建恢复目录，将选定的升级前 `.bak` 复制为 `clipboard.sqlite`，复制需要的其他设置/启动项文件，但不要复制旧的 `clipboard.sqlite-wal` 或 `clipboard.sqlite-shm`；通过 `--data-dir` 指向恢复目录运行匹配旧版本的程序。备份不包含升级后新增的历史，所以当前目录应保留以便后续取回。
