# 开发状态与约束

## 当前范围

已实现统一 Qt Widgets 宿主、托盘、中文设置、共享浅深主题，以及启动器、剪贴板、手势、锁屏的主要运行链。另有自动更新、GitHub Actions、当前用户登录自启、受限管理员辅助进程，以及 RTF/可序列化 MIME 格式保存。具体使用与限制见 [系统集成与数据](system-integration.md)。

仍需完成或扩大验证的项目：

- 真实 UAC 同意/取消、管理员窗口回贴/右键/手势，以及注销再登录自启的桌面验证；普通 CTest 只验证隔离注册表和禁止输入的辅助进程。
- 混合 DPI、多显示器、实体鼠标/键盘与长时间运行矩阵。
- 手势复杂路径的全部旧行为对等性和更多外观参数。hua、BlackLock 配置迁移已明确不在范围内。
- 锁屏的睡眠/唤醒、热插拔、异常注入与完整应急路径。
- 真实 Hopy 历史/HLaunch 启动项只读导入和跨机器部署。MT 自启只管理自身注册，不接管旧工具的启动项。
- 真实跨版本在线更新；v0.1.0 为首个公开版本，隔离更新测试不代表已完成两个正式版本之间的升级验收。

单测、隔离预览、真实桌面输入、干净机器部署和正式发布应分别记录，不能互相替代。原始本机日志、历史截图和带机器路径的开发记录保留在被忽略的 `docs/ai/`、`out/` 和原型 `evidence/` 中，不属于公开源码包。

CI 使用 Windows Server 2022，它没有 Windows 11 的 DWM 圆角接口：专用圆角测试明确跳过，菜单交互和布局继续检查。Windows 11 上保留完整 DWM 断言；CI 通过不代表已验证 Windows 11 的所有桌面效果。

## 架构

- `mt_core`：设置、持久化、领域模型、识别与版本解析。
- `mt_platform`：Windows 原生能力、资源所有权、进程与更新安装助手。
- `mt_updates`：异步版本检查和下载，系统 Schannel TLS。
- `mt_ui`：Qt Widgets、统一 QPalette/QSS 和主题。
- `mt`：唯一 QApplication、托盘、全局快捷键与模块生命周期。

模块独立启停，不创建自己的托盘、自启项或应用事件循环。数据库连接在所属线程创建、使用和销毁。输入钩子回调不做磁盘、网络或 Shell 操作；后台结果必须受对象生命周期与代次限制。

启动项图标由最多 3 个轻量辅助进程复用提取，单次超时 3 秒，空闲 30 秒回收；当前页和搜索可见项优先，缓存按最近使用淘汰，避免满额后整体清空。GUI 线程只接收结果、解码小图并更新对应控件；Shell 扩展与文件图标查询在辅助进程执行。启动、定位和导入仍使用独立任务，图标队列保留一个明确操作的执行槽位。

## 界面约定

- 品牌显示为 **MT**；EXE、命名空间、资源前缀等技术标识为小写 `mt`。
- 全部界面中文，系统字体，共享 `resources/theme/theme.json` 的浅色、深色和系统跟随主题。
- 正式产品 Logo 已于 2026-10-29 确认为 `resources/logo.ico`，2026-10-30 明确移除外围白色背景，仅保留黑色圆角图形和内部 MT 字样；`resources/logo.png` 为透明源图，ICO 包含多个尺寸。EXE、应用窗口和托盘共用此文件，不采用设计探索中的其他候选稿。
- 功能图标来自 Lucide 0.460.0（ISC），没有合适图标时才考虑 Tabler（MIT），不手绘来源不明的图标。产品 Logo 不属于功能图标。
- 启动面板默认 4×7，可配置 3–20 行列；保留底部分类、固定空槽和隐藏附属搜索。
- 启动面板普通唤起以鼠标为中心，按当前屏幕和实际面板尺寸定位；靠近边界时优先保持面板在工作区内。边缘唤起保持贴边，附属搜索沿用主面板定位。
- 启动项焦点随鼠标按下和拖放落点移动；拖动、取消或隐藏后清除按下状态，不能积累多个蓝色背景或误触发启动。
- 按住启动面板空槽、网格间隙或底部留白可移动面板，附属搜索跟随移动；项目和分类继续使用各自的拖放操作。松手、失焦、隐藏或失去鼠标控制权后结束窗口拖动。
- 启动面板标题栏默认留空，不显示 MT 或搜索图标；悬停启动项时显示名称，超宽时省略并保留完整提示，离开、空槽或隐藏时清空。搜索通过菜单、Ctrl+F 或直接输入打开。启动项与标题栏按钮悬浮时仅显示细边框，分类仅提亮文字；空槽使用轻量虚线边框，当前分类有强调文字和指示线。附属搜索默认收起，列表使用统一行高，无结果时显示中文提示；Esc 先清查询，再关闭搜索并恢复网格焦点。
- 剪贴板以历史为主体，搜索默认收起，分类图标可取消；无“全部”按钮。收藏/置顶/删除常驻，序号与时间分开，不增加来源采集。
- Windows 11 DWM 提供不透明面板和菜单的圆角、边框和阴影；整窗不透明度可调，不恢复透明背景自绘主窗口阴影或硬裁切。
- 托盘菜单依次分为快捷操作、暂停控制、设置与关于、退出四组；暂停剪贴板记录在暂停锁屏前面，两项相邻。主题在统一设置中选择，托盘不再提供切换主题项。
- 托盘“关于”直接进入统一设置的“关于 MT”页；已有设置窗口复用并保留草稿，最小化时恢复显示，左侧导航同步选中。设置原生标题为“设置 - MT”，避免应用名重复。
- 设置页移除泛化副标题、宣传语、字体与图标介绍、原生实现说明和不可修改的固定行为卡片；保留运行状态、关键操作后果与解锁提示。外观并入常规，移除数据位置展示；侧栏六页，默认常规。锁屏名称同步到设置、托盘及错误信息，行为仍为屏幕遮挡，不改为 Windows 账户锁定。
- 设置下拉框从构造阶段统一列表式弹出，避免残留菜单模式留白导致选项裁切；短列表完整显示，长列表最多 10 行并滚动，沿用共享主题及 Windows 11 DWM 框架。
- Tooltip 保留 Qt 默认外观和 Windows 平台配色，跟随系统主题；不使用应用 QSS 或固定 Fusion 颜色覆盖。
- 手势与锁屏在统一设置中配置，无独立管理面板。手势轨迹只是必要局部绘制。
- 启动面板主窗口支持手势，普通右键点击仍打开菜单；自身其他窗口继续排除。隐藏/重开和原生句柄变化同步接纳状态，已取消轨迹不复活。管理员窗口须开启常规页的“管理员窗口支持”并确认 Windows 权限提示；主界面保持普通权限。

## 开发和数据边界

所有业务代码全新编写；旧 Hopy、HLaunch、hua、BlackLock 仅为只读行为和格式参考。运行验证使用独立数据目录，不修改旧应用、自启或真实数据。正式用户数据的格式变更需设计兼容与恢复方案，失败时不得删除旧库或覆盖为空配置。

导入范围仅为 Hopy 历史（及图片、HTML 附属内容）和 HLaunch 分类/启动项（含必要快捷方式）；不迁移旧工具偏好、自启、hua 规则或 BlackLock 密码。现有 MT 历史数据库从 schema 1 升至 2 前创建一致性备份；未知版本或无版本标记的非空库拒绝写入。

当前采用 C++23、CMake、静态 Qt、静态 CRT，不引入 QML、WinUI、WebView 或动态业务插件。第三方原生 C 库可保留。构建步骤见下文[本地构建](#本地构建)；更新和发布分别见[更新设计](updating.md)、[发布流程](releasing.md)。

自更新继续单 EXE 分发，使用主程序的临时副本执行替换；父进程身份校验和正常退出后再启动新版本。新程序及回退使用正常窗口方式，已完成更新的助手在启动后清理，原路径、数据目录、旧 EXE 备份和失败记录保留。隔离验证覆盖中文空格文件名及原生窗口可见性，真实线上跨版本升级仍待验收。

Actions 与后续 Release 的程序文件统一为 `mt.exe`，更新元数据同步匹配此文件名；已发布 v0.1.0 的旧命名版本需手动下载一次新版本。压缩包与 Actions 产物集合仍可标注版本、平台和架构。

## 本地构建

以下命令均在仓库根目录执行。开发构建也可从通过的 [Actions 运行](https://github.com/Hunlongyu/mt/actions)下载 `mt-windows-x64` 产物，其中的程序为 `mt.exe`。

需要 Visual Studio 2022 或更新版本的 C++ 工具链、Windows SDK、CMake 3.29+、Ninja、PowerShell 7 和静态 Qt SDK。CI 固定使用 **Qt 6.11.2**；MSVC 通过 `vswhere -prerelease` 自动发现。

下载与 CI 相同的静态 SDK（[yuanpeirong/buildQt · Qt6.11.2_rev0](https://github.com/yuanpeirong/buildQt/releases/tag/Qt6.11.2_rev0)）：

```powershell
./scripts/get-qt.ps1
./scripts/build.ps1 -QtRoot C:/mt-deps/sdk/6.11.2-static/msvc2022_64_RP
```

脚本固定下载 `Qt_6.11.2-static-Release_msvc2022_64_RP.7z`，核验 SHA-256，并获取相同版本的官方源码归档用于发布材料。RP 精简包包含 Qt Base、Tools、Translations、SVG，满足当前组件需要；不自动追踪上游 latest。

已有静态 SDK 时，直接把其目录传给 `-QtRoot`。也可从校验过的官方源码自行构建：

```powershell
./scripts/build-qt.ps1 -InstallRoot C:/mt-deps/qt
./scripts/build.ps1 -QtRoot C:/mt-deps/qt
```

产物位于 `out/build/win-static-release/mt.exe`。默认执行 CTest；`-SkipTests` 仅跳过测试运行，`-Fresh` 重新探测编译器。

独立示例预览：

```powershell
./scripts/preview.ps1
./scripts/preview.ps1 -Settings
./scripts/verify-preview.ps1
./scripts/verify-update.ps1
```

`--preview` 使用示例数据，不安装输入钩子、不监听剪贴板、不启动外部程序、不联网检查更新。`verify-update.ps1` 只在临时目录中替换程序副本，并以预览模式重启，验证成功、损坏文件、占用失败和取消安装。原生输入与锁屏测试需单独显式执行，普通 CTest 不会锁住桌面。

### README 预览图

公开预览图位于 [docs/images](images/)，来自当前版本原生程序的示例数据渲染。使用 `--preview --data-dir <新的隔离目录> --evidence <输出目录> --quit-after 6000` 导出深浅两套主题，选取启动面板、剪贴板与设置页面；设置图将导出的 `settings-clipboard-<主题>.png` 保存为 `settings-<主题>.png`。

导出图片仅包含控件内容，不包含 DWM 管理的系统圆角、边框和阴影。更新图片前检查示例内容、图片清晰度及 README 相对路径，不将真实历史数据或本机诊断截图作为公开素材。

## 项目结构

```text
src/app/                    应用装配与生命周期
src/modules/                四项内置功能
src/infrastructure/         设置、存储、更新与中文文本
src/platform/windows/       Windows 输入、窗口、Shell 与更新助手
src/ui/                     共享主题、控件和设置窗口
resources/                  统一主题、图标、翻译和许可证
tests/                      单测与显式开启的桌面集成测试
scripts/                    SDK、应用构建、验证和发布打包
.github/workflows/          Windows CI 与标签发布
prototypes/                 可重建的 HTML 界面原型
docs/                       更新、发布、开发契约和验证记录
```

原型通过 `node prototypes/desktop/build.mjs` 和 `node prototypes/settings/build.mjs` 生成。原生与原型共用 `resources/theme/theme.json` 和 `resources/icons/lucide/`。
